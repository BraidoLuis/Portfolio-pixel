# Capas dos projetos

Coloque as imagens dos seus projetos nesta pasta.

Exemplo: `public/projects/meu-projeto.webp` deve ser referenciado em
`content/projects.ts` como `thumbnail_url: "/projects/meu-projeto.webp"`.

As capas WebP atuais reutilizam imagens dos repositórios de SPA Express, FriBolos,
NB Arquitetura, Projeto Transformação BJJ, SPE/SAPE e Orçamento. As origens estão
em `docs/AUDITORIA-CONTEUDO.md`. O Portfólio Pixel usa seu mapa existente.
Projetos sem imagem continuam aceitando `thumbnail_url: null`.
